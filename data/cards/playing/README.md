# Playing cards: pictures of the ready-made deck

The ready-made deck **Playing cards** shows these pictures (owner
2026-11-24). Four colours, as the deck's own: spades black, hearts red,
diamonds blue, clubs green.

| files | by | licence |
|---|---|---|
| `svg/{A,2..9,T,J,Q,K}{s,h,d,c}.svg` (52 cards) | heratexx, "Classic 4 color poker deck (SVG)", https://opengameart.org/content/classic-4-color-poker-deck-svg | CC0 1.0 (public domain) |
| `svg/joker_black.svg`, `svg/joker_red.svg` | SoftCalc, drawn to match (the set has no jokers) | MIT, as SoftCalc |

The 52 SVG files are as downloaded by the owner, unchanged. `png/` is
made from `svg/` by `python tools/render_cards.py` (368 x 512, through
Microsoft Edge) and embedded in the exe as `cards/playing/<name>.png`.
