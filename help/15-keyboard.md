# Keyboard and mouse

## Input box

| key | does |
|---|---|
| Enter | calculate |
| Enter on an empty Input | repeat the last History line |
| Up / Down | earlier lines you typed, highlighted in History; Down past the newest brings back your draft |
| Esc while stepping | take the highlight off and bring back your draft |
| an operator on an empty Input | starts with `answer` |
| Esc after that | takes `answer` away, keeps the operator (C on the keypad too) |
| right-click | Undo, Cut, Copy, Paste, Delete, Select All, Clear Input |

## History

| key or mouse | does |
|---|---|
| click | put the line back in Input; Up and Down go on from it |
| click the highlighted line | take the highlight off, keep the line in Input |
| Shift+click | insert the result at the caret |
| Ctrl+C | copy the selected entry |
| right-click | Use Expression, Insert Result, copy, Delete, Clear History |

## Stopwatch

In the main window and the Stopwatch & Timers window (Dates and time):

| key | does |
|---|---|
| F8 | start the stopwatch, or stop it (the time goes to History) |
| Shift+F8 | a lap |
| Ctrl+F8 | pause, or go on |
| Ctrl+Shift+F8 | reset |

## Graph window

| key or mouse | does |
|---|---|
| wheel | zoom around the mouse |
| Shift+wheel / Ctrl+wheel | zoom x only / y only |
| + / - | zoom in / out |
| drag, arrow keys | move |
| F, Ctrl+F | fit y to the lines |
| Home | start range |
| click (Trace on) | copy the traced value |
| right-click (Trace on) | copy or insert x, y or (x, y) |

## Customize Ribbon

| key | does |
|---|---|
| Enter, double-click | add the selected command |
| Delete | remove the selected row |
| F2 | edit the selected row |
| Ctrl+Up / Ctrl+Down | move the selected row |
| Esc while dragging | cancel the drag |

## Help

| key | does |
|---|---|
| F1 | open Help at the topic for the window you are in |
| click an example | put the line in Input |
| Enter or Down in Search | go to the topic list |
| Esc | close Help |

## Menus

Alt and the underlined letter open a menu, as in other Windows programs:
Alt+V opens View, Alt+C Conversions.
