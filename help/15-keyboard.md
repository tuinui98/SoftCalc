# Keyboard and mouse

## Input box

| key | does |
|---|---|
| Enter | calculate |
| Enter on an empty Input | repeat the last History line |
| Up / Down | earlier lines you typed; Down past the newest brings back your draft |
| an operator on an empty Input | starts with `answer` |
| right-click | Undo, Cut, Copy, Paste, Delete, Select All, Clear Input |

## History

| key or mouse | does |
|---|---|
| click | put the line back in Input |
| Shift+click | insert the result at the caret |
| Ctrl+C | copy the selected entry |
| right-click | Use Expression, Insert Result, copy, Delete, Clear History |

## Graph window

| key or mouse | does |
|---|---|
| wheel | zoom around the mouse |
| Shift+wheel / Ctrl+wheel | zoom x only / y only |
| + / - | zoom in / out |
| drag, arrow keys | move |
| F, Ctrl+F | fit y to the lines |
| Home | start range |
| click (Trace on) | copy the traced value |
| right-click (Trace on) | copy or insert x, y or (x, y) |

## Customize Ribbon

| key | does |
|---|---|
| Enter, double-click | add the selected command |
| Delete | remove the selected row |
| F2 | edit the selected row |
| Ctrl+Up / Ctrl+Down | move the selected row |
| Esc while dragging | cancel the drag |

## Menus

Alt and the underlined letter open a menu, as in other Windows programs:
Alt+V opens View, Alt+C Conversions.
